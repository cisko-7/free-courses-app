# 📌 БЫСТРОЕ РЕШЕНИЕ: Ошибка "DC_FORBIDDEN"

## Что произошло?
При открытии админ-панели ошибка:
```
Не удалось загрузить статистику: DC_FORBIDDEN: требуется вход администратора
```

## Причина
Функция БД `admin_stats()` требует верификации администратора через ПИН. Если ПИН давно установлен и более 30 минут не вводился — доступ блокируется.

## Решение (выполнить в Supabase SQL Editor)

### ⚡ ВАРИАНТ 1: Сбросить ПИН полностью (проще)

```sql
-- Скопируйте и выполните этот запрос:
delete from public.admin_secrets;
delete from public.admin_pin_attempts;
```

✅ **Готово!** Администратор сможет входить без ПИНа.

## Если всё ещё не работает

1. **Проверьте, что вы администратор:**

```sql
select email, raw_app_meta_data ->> 'role' as role
from auth.users
where email = 'ваш-email@example.com';
```

Должна быть роль `"admin"`

2. **Если нет — назначьте администратора:**

```sql
update auth.users
set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role": "admin"}'::jsonb
where email = 'your-email@example.com';
```

3. **Выйдите и снова войдите в приложение** — роль попадёт в JWT токен

4. **Снова выполните сброс ПИНа:**

```sql
delete from public.admin_secrets;
delete from public.admin_pin_attempts;
```
