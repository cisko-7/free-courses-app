# 🚀 Быстрый старт: DevCourses AI Autopilot

## 1. Получите бесплатный Google Gemini API ключ

1. Перейдите: https://aistudio.google.com/apikey
2. Нажмите "Create API key"
3. Скопируйте ключ (AIza...)

## 2. Добавьте ключ в .env.local

```bash
NEXT_PUBLIC_GEMINI_API_KEY=AIzaSy...
```

Или вставьте прямо в админке (вкладка "🤖 ИИ-Пилот").

## 3. Перезапустите приложение

```bash
npm run dev
```

## 4. Откройте админ-панель

http://localhost:3000/admin → вкладка "🤖 ИИ-Пилот"

## 5. Проверьте работу

В Admin Commander напишите:

```
Привет! Проверь статус системы.
```

ИИ должен ответить и показать статус системы.

## 💡 Примеры команд

- "Включи техобслуживание на 1 час"
- "Дай user@test.com 100 XP"
- "Покажи баннер: Новый курс доступен!"
- "Забань user@spam.com"
- "Создай задачу по Python: найти максимум в массиве"
